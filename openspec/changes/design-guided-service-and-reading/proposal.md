# 阅读优先与用户必要字段配置

## 原因

用户继续指出当前会话的信息层级与样式问题，要求历史和日志后置、按需展开；翻译服务配置只让用户处理实际需要且可理解的字段。R73保留的完整数据、资源关系和高级能力继续存在，本轮调整默认呈现与引导顺序，不能通过隐藏信息绕过服务资格或移除已承诺能力。

## 本轮变更

- 新完整设计候选 `guided-service-reading-20261030`：当前原句、译文和必要阅读动作优先，预览为辅助；历史、原始提取和Hook诊断移到阅读之后并默认折叠，保留独立查看和完整数据操作。
- 服务先选明确供应商/引擎及具体接口路线，再按该资源契约展示必要字段、可理解的缺项原因和下一步；预设信息与可选高级字段不堆成首次配置负担。
- 独立呈现目录精确引用现有13协议、21预设和4离线候选，区分用户必填、可信默认值和适用高级项；不编造服务地址、模型ID、实际探测或兼容性。
- 同步准确PRD、技术合同、呈现目录和GD-01～12分层计划；新增静态正反例与真实Playwright设计检查，保留此前FL/SS/OT及文档检查。
