# 首版数据库字段设计补全

## Why
用户指出架构文档缺少数据库字段设计；原方案只有SQLite选型和主表名称，无法检查字段身份、引用、配置版本、清理与事务的具体约束。

## What Changes
补充独立profile写库与包内只读辞书的设计DDL、字段字典、索引与关系图、迁移/保留/秘密引用/事务方案；增加隔离SQLite设计正反例和确定性导出检查，集中展示到离线HTML架构报告。

## Impact
仍是设计与工程准备，不实施产品migration、不创建用户库、不改产品代码、不运行游戏或模型。继承原PRD、架构边界、128定义/153组合及其not_run状态；R4原件归档，R5仅记录本轮候选字段设计身份，不提升设计审批。没有提交推送。
