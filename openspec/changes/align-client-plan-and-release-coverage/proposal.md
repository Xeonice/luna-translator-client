# 最新设计到客户端、PRD、测试与准出的同步规划

## 原因

R74 已记录阅读优先与必要字段引导的新完整候选，但当前客户端、旧技术说明和原97来源/153组合发布计划不能因此被读为已覆盖新要求。用户要求先把客户端技术文档、PRD、测试用例与准出判断同步到最新设计。本轮只完成文档、规划和对应可执行检查，不实施产品或新增UI。

## 本轮变更

- 明确以 guided 候选作为最新目标；当前正文独立首屏，三份记录后置默认折叠，配置按用途、品牌、明确接口显示必要字段。新设计仍 pending_review；旧批准与产品运行状态各自保留。
- 对照实际客户端源码，记录当前能力、目标差距、正确模块Owner、复用点、存储/契约影响和分片依赖，避免把既有实现写成计划或把目标写成已实现。
- PRD与总执行计划同步任务边界；不得改FP权威表或其生成对象。本轮不授权任何产品源码、公开DTO、DDL、依赖、运行包或新UI。
- 新增当前覆盖合同，逐项引用 PA12、OT16、SS12、FL10、GD12 与独立GUI01～08，共70个来源，并按适用层、环境和服务/协议/引擎/游戏变体形成附加必需执行闭包。旧128定义/153组合、97来源与111CSV原身份、内容和历史状态保留。
- 新静态/负例工具与只读准出评估接入统一verify，发布路径无条件检查新增范围，缺真实adapter、确认设计或同包证据时继续阻断。

## 状态和非目标

工作项基于 FP1-20261030-R74 与完整2087源冻结map。文档/工具工程检查、候选设计确认、产品逐层运行和正式发布分别判断。本轮新产品计划保持 not_run，外部缺项标 blocked；守卫自测、旧包、设计样例或有限稳定性runner均不能产生完整首版通过。旧候选/PNG/token、技术锁、活跃change/phase及产品/批准/历史状态不变，不提交或推送。
