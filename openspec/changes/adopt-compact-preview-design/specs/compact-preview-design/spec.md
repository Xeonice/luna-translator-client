## MODIFIED Requirements

### Requirement: FP-03 Compact preview preserves complete information and automatic flow
The design SHALL use the approved compact preview with accessible complete details through the existing shared component.

#### Scenario: shared-session-and-target-preview-stays-compact-with-accessible-details
- **GIVEN** the current complete design session or target review displays preview
- **WHEN** the user reads status, pauses, recovers or opens details
- **THEN** the compact card remains bounded and the complete identity and diagnostics remain accessible, while original capture time, ownership isolation and automatic preview semantics are retained.
