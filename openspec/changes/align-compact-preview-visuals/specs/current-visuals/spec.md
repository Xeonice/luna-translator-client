## ADDED Requirements

### Requirement: VCP-001 Current reviewed visual alignment
The production preview SHALL follow the exact currently approved compact layout and material tokens, including real responsive container behavior, truthful frame state/time and no horizontal overflow. It SHALL preserve frame validity, ownership and permission clearing.

#### Scenario: compact-preview-matches-the-current-reviewed-source
- **WHEN** the declared current state and presentation is exercised
- **THEN** its actual visual/behavior evidence is inspected against the current reviewed source
- **AND** wrong state, stale frame, hidden control, clipped content, fake reference or producer interference is rejected

### Requirement: VCP-002 Current reviewed visual alignment
