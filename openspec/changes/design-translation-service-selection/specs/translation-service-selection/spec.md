# 统一服务选用

## ADDED Requirements

### Requirement: TSS-001

系统 MUST 保持统一浅层选择与独立配置，未配置不能选，不提升产品验收。

#### Scenario: single-shallow-service-selection-and-separate-configuration

- GIVEN 既有R71设计与已保存配置
- WHEN 用户选用或配置翻译服务
- THEN 入口、资格、版本、作用域及启停一致，原配置和历史不被隐式改写，设计与产品执行分别留证。
