# 平铺翻译服务配置与当前会话

## 原因

用户要求翻译服务配置原有三类型与五个子页签、当前会话原有三个页签改为真正同页平铺，并审查重复、偏高级和排障信息的默认呈现。现有服务资格、作用范围、不可变保存版本、独立启停和历史归属是承诺能力，不能因减少页签而删除。

## 本轮变更

- 新完整设计候选 `docs/design/first-product-v1/candidates/flat-service-session-20261030/`：服务类型在同页管理，连接、模型、用途、测试和已保存概览以区块组成；根据当前对象显示相关字段。
- 当前会话同页提供当前状态与常用控制、全部提取事件及Hook事件；分区保持独立筛选和分页，预览持续存在。
- 高级字段、完整身份、诊断原文及技术性说明从按需入口查看；基本状态、错误原因、恢复操作与原有能力保留可达。
- 同步准确相关PRD、技术合同、机器目录和FL-01～10分层计划；新增静态、正反例与真实Playwright设计检查。
