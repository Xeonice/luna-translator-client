# 独立用户接受裁决

采用固定代码注册的决定与完整保留证据清单。裁决绑定用户原话、候选源码/归档/可执行文件、原Root/Native/React回执、27组合54原帧、独立参照、实际观察事实和原始错误。任何文件hash、尺寸、案例集合、几何、可见语义、执行身份或原件完整性变化均拒绝；只接受已明确审阅的像素差异，参照自校准与新包保持原零差异规则。原始producer和Root失败不回填。

验证器source与被验候选source分开。候选须保持签名封印的Source62和精确S5归档；当前工作树只允许本次明确的QA/文档增量，不允许任何产品源码漂移或新增未知源。完整旧source快照可逐文件重算，不能用包hash匹配代替当前实际产品文件核对。代码注册决定的身份不由CLI或JSON选择其他策略。

Gate接线：General Native遇到精确已登记候选时执行新的独立裁决路径，生成新nonce/时间的裁决回执；普通捕获路径和原PNG比较器不变。校验裁决时重新读取所有绑定原件及语义/几何并逐图重算，禁止仅相信status/错误字符串或mock正例。非登记包走原严格路径；登记决定损坏必须失败，不回退成重拍。Root verify另注册同一真实裁决检查及负例测试。全局错误仍保留，不能把局部接受当产品完成或安装许可。

原件校验应按同一不可变批次的唯一archive验签，避免每帧反复解包同一2GB应用；不得以路径/mtime/旧passed缓存代替内容hash/真实签名。实际验证不启动GUI、不再截图，不触碰正常Luna、HMR或游戏。
