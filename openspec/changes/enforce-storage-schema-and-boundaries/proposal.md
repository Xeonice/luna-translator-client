# 存储验收、全字段边界与结构一致性程序

## Why
用户要求把存储模块验收和字段边界情况一并纳入，且由可编译或校验的程序确保一致性。前轮只运行设计DDL重点测试和派生文档核对，尚缺逐字段边界覆盖及生产迁移结果对照的真实执行门禁。

## What Changes
增加独立冻结的schema契约、只读真实数据库结构比较程序、全字段适用边界义务/实际探针、存储验收子检查与真实adapter执行协议，并接入统一开发/发布门禁及HTML报告。类型、NULL、默认值和原CHECK在精确隔离字段投影中验证，完整业务/FK/故障/迁移验收由实际生产adapter承担。

## Impact
本轮仅设计规范与工程校验设施。不得在产品目录创建storage/migration实现，不运行用户数据库，不更改游戏/模型或原128定义/153执行组合的not_run。实际生产adapter仍缺失，发布和存储产品验收必须拒绝；守卫夹具不替代生产迁移。R5原件归档，R6只登记明确授权追加约束身份，不提升整稿或数据库字段审批。无提交推送。
