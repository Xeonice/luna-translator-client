# 产品完成与准出

统一入口为npm run verify；工程、工作项交付与产品发布分别判定。默认engineering或quick通过不表示产品通过。delivery按实际影响核验工作项；release或--require-product-complete要求全部九类门禁与完整真实产品义务。

## 完成条件

G01～G09适用项均有当前真实结果。G09为正式人工门禁：未确认blocked、拒绝failed、未执行not_run，不能用工程绿色小计绕过。只有受授权明确确认的当前完整视觉范围才通过；相关变化失效。

正式产品仍要求同一最终签名包、源码/Core/资源、实际窗口权限/恢复、SR/MO/Never7/樱之诗逐款原约定回归、真实翻译与分词注音词典，以及原153组合、RW逐层和存储专项。受控组件、CLI探针和门禁自测不相互替代。缺凭据或实机输入记录blocked，不删用例不伪造passed。

## 回执和推进

结果绑定真实命令、输入身份、原件、断言、阶段与副作用。存在failed/blocked/not_run/过期/缺失/混包，产品保持incomplete，禁止宣布产品合格或发布；同一未完成阶段可以修复和继续独立工作。工作项的next_stage_allowed仅授该检查阶段，不得提升next_product_stage_allowed。

门禁实现完成与当前产品完成独立：32组隔离正反例和真实Codex触发可证明门禁有效，但测试审核、模拟游戏或合成执行记录不能进入正式产品。原始失败与重跑均留存。

唯一用户可读结果见reports/gates/index.html；视觉只链接reports/visual-comparison/index.html。当前产品未获本轮正式准出，不因本次工具实施重写为完成。
