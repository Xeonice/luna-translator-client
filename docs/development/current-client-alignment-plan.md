## 3. 整页交付合同

每个受影响页面在编码前形成独立交付合同，放入对应OpenSpec迭代卡；本计划不一次授权所有源码路径。

| 必须填写的项 | 具体内容 | 未满足时的处理 |
|---|---|---|
| 功能旅程 | 实际入口、用户输入、成功结果、取消/失败/重试、与其他状态的独立性；追到FP/AI-CFG/RW/HP及专项验收ID | 缺入口或关键分支保持部分实现 |
| 页面区域 | 按已确认设计列首屏/辅助区/折叠区/固定操作区及完整按钮清单、先后关系、共享组件和状态归属 | 不以去Tab、按钮存在或局部article相似结案 |
| 数据与命令 | 逐项注明已有真实端口/DTO、须扩展合同、Rust权威Owner及兼容/存储影响 | 目标命名不得当现成API；依赖未实施不能造UI假能力 |
| 视觉与状态 | 当前设计页/状态ID、独立参照批准、逻辑client视口/字体/主题/数据/实际词法状态、宽窄/长文/200%与几何锚点 | 同偏好不等于同渲染；组件/桌面裁图不能代替整窗 |
| 测试与原件 | 各用户旅程和区域映射到真实层/用例/执行器、包/源/资源身份、截图与独立重算 | 缺项写not_run/blocked；已有失败保留，不自动刷新原图 |
| 页级完成 | 功能、排布、错误恢复、可访问性和适用原生/服务证据全部闭合 | 内部切片可单独记录实现，但页面任务不关闭、产品不推进 |

当前Main已在实时组件入口修正C1双列/窄窗、角色字号、七动作及重复控制/来源层级，受控断言与同数据截图分别留证；这些源码修正未自动进入已安装包。原Main纯文本与真实SourceText的分词/注音状态、全量摘要窄查询、C35完整组合及原生标题裁切仍各自核验，未关闭整页。

手动页另按FP-10/C25收敛直接编辑区、设置入口、动作顺序及常驻结果；恢复结果须核手动来源，不因Hook句缺gameId而复用。共享服务选用、三种源语言和真实阅读能力保留，未有有效语言投影不硬编码目标；紧凑选用及富文本组合参照缺口与Native层分别保留。

三页局部布局补充已获用户确认，精确9源及manifest见[批准记录](design-approval-layout-refinements-20261107.json)。历史同轨/16px内容线、通用行安全边（新结构按独立批准替代其24px组距/组织）和停止会话三旧句动作按M13既有端口实施；有效预览、固定词句及保存语义保留。补充source-authority只判批准源与描述符，不授真实组件、参照、Native或产品通过。局部真实组件检查、未遮罩图像差异及同签名包观察另建回执，原809状态及整页关闭条件不减。

当前卡、记录区和预览可以各自实施与测试；整页完成仍取决于完整组合。正式客户端测试使用其实际逻辑client宽度，不把1600px模拟桌面里的1040px假窗口等同1040px真实client。调整客户端布局不改变游戏窗口大小。

## 7. 完成判断与文档维护

- 一个页面只在完整承诺功能、排布/状态、可访问性、真实接口和适用层证据全部通过后关闭。模块存在、旧Tab消失、按钮可点、编译和少量语义断言通过均不足以关闭页面。
- 每次实测单建`run_id`，记录准确源码/包/资源/环境、实际命令和断言/图片/原件hash。未执行写`not_run`，外部条件不足写`blocked`，失败及重跑均保留；原计划定义不回填通过。
- 现行文档采用**覆盖更新**：直接修改对应原章节和现状表、移除重复/失效描述并同步交叉引用，不在末尾追加日期版“本轮/最新”规则。PRD管行为，设计管交互外观，技术稿管实现合同，本文管任务；同一事实只保留一致的现行解释。
- 历史OpenSpec、基线与实际执行原件按原身份保留，只用于追溯；历史不是平行的当前规范。改变确认过的产品行为/架构需独立记录影响，不能以文档清理降低目标或默认批准新字段。
- 本轮文档与计划review、工程检查和产品准出分别出结论。缺口未清零时产品保持incomplete，后续工作按同一未完成阶段修正，不宣称发布或进入已验收阶段。
