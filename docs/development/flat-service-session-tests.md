## 功能审计表

| 检查对象 | 用户价值与现行规则 | 必须保留的能力 / 对照 |
|---|---|---|
| 云端/本机/LLM类型导航 | 合并到统一列表，类型作为标签/说明；不再切走其他已添加服务 | 三类执行语义、状态/禁用原因、添加模板入口；FL-01/02 |
| 用途/连接/模型/模板参数/测试运行五Tab | 移除重复实体导航，同页展示当前资源适用字段和测试 | 连接/模型/用途与离线资源身份、引用关系和版本；FL-01/03 |
| 配置页重复日常翻译选择/启停 | 展示有效来源并复用浅层选择器入口，避免另建一套选用流程 | 主/对照有序去重、范围/继承、独立自动开关和当前句重译；FL-03、SS原计划 |
| 传统HTTP及离线中的LLM字段 | 对象不适用时隐藏，不要求假模型ID/URL/Key/提示词 | 实际协议/认证/语言、系统/资源/路线字段和未知条件门禁；FL-02、OT原计划 |
| 参数/模板/上下文/运行策略/多Key | 放在适用对象高级区，保留摘要和展开入口；低频不等于无用 | 三态参数、预算/范围、超时/并发/重试/回退/缓存、独立密钥状态；FL-04 |
| 精读与语境查词 | 独立区分别设置用途及模型，不借用翻译配置 | 固定词句、独立输出模式/策略/测试，不自动启用或发送；FL-04 |
| 演示返回/故障注入 | 移至页外评审工具，产品表单不显示模拟执行控制 | 测试对象、明确样句、取消、错误阶段/过时记录；FL-09 |
| 正文/提取/Hook三个会话Tab | 改为同页独立区域，摘要/入口同时可见，细节可按需展开 | 三数据集边界、全量事件、脱敏native事实、独立筛选/页/跟随/搜索/导出和缺口；FL-05～08 |
| 与当前资源无关的空按钮/成功标签 | 无动作不留可执行入口，未知状态解释原因，不以设计样例冒充通过 | 真实可执行动作和恢复路径；FL-09/10 |

这份审计只调整呈现，不授权删除任何AI-CFG/RW能力。若后续发现能力应调整，单独记录需求影响并审阅，不能在布局修改中静默删减。
