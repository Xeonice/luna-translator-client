# 首版视觉基准：暗色磨砂与分层表面

用户已确认 `macos-material-case-v1` 的整体风格，作为第一批产品的视觉基准。完整设计稿按此统一，各次布局与交互的确认范围见[当前设计说明](README.md)；风格或设计确认不提升任何正式产品回归状态。

## 共同的窗口语言

以整个窗体连续的暗蓝灰磨砂底为基础，背景的蓝色、亮部与暗部经过模糊后透入。标题栏、导航和正文属于同一窗体，不切成互不相干的白、青、灰色大块。

表单、输入区、阅读提示和结构卡片使用更厚的中性灰内层表面；文字和图标保持独立清晰。边界以细暗线、局部高光和柔和阴影表达，不增加连续明亮外框或装饰性玻璃按钮。

| 层次 | 共享变量与默认值 | 使用位置 |
| --- | --- | --- |
| 窗体 | `--material-shell-fill`：rgba(35,38,49,.8965)；25px / 105% | 主窗、设置、学习、字幕 |
| 厚内面 | `--material-inset-fill`：rgba(58,58,68,.863)；20px / 90% | 分组表单、输入、原文卡与解释卡 |
| 控件与选择 | 中性灰透明填充、柔和浅灰选择态 | 按钮、分段控件、列表选择 |
| 主要文字 | #e9e9ef | 原文、译文、标题、字段值 |
| 次要文字 | #b0b2c0；辅助 #9495a5 | 来源、说明、状态与元信息 |
| 强调 | 中性浅灰 #c4c5cf | 链接、焦点、结构引用 |
| 外形 | 窗体16px、内面13px、控件7px | 同层级保持一致 |

图标统一由 [icons.js](icons.js) 提供：24×24视框、1.65圆头描边、常规18px视觉尺寸，使用currentColor；设置分类和标题不使用彩色底块，不再混用Unicode图标。主要操作采用深灰底、白字，选择与链接靠中性亮度区分；彩色只用于小面积必要状态，背景和游戏画面保留原色。

准确值与浅色适配集中维护在 [material-tokens.css](material-tokens.css)。浅色是同一套层次的可选适配；默认外观采用已确认的暗色案例。

## 覆盖页面

- 游戏库、当前会话、历史与手动翻译共享同一窗体和内容层。
- 目标程序、检查与选流面板继承窗体材质，状态变化不改变整套色调。
- 设置十类导航、服务连接、模型、用途、测试与参数页使用统一分组表单。
- 字幕、词卡、词典和精读采用相同磨砂层次；保留阅读字号、注音、结构引用和32pt操作行。
- 菜单、确认弹窗、失败与恢复提示统一边界、文字、按钮和状态颜色。
- 截图画廊、旅程和对照页也采用该风格，避免评审入口出现另一套调性。

系统减少透明度时退为同色系实色表面。正文滚动、固定底部操作、200%字号与小屏布局继续有效。

## 验证与边界

Playwright从首次配置、连接与选流开始走完整流程，再采集所有页面；另外直接对照已确认案例与游戏库、设置、字幕、精读截图。检查实际取景、层次和可读性，不能仅凭CSS中有blur参数认定达标。

HTML表现浏览器中的材质视觉。原生材质、窗口行为、游戏与模型功能仍按原开发计划验证；真实游戏画面仍保留此前证据归属，设计用译文与词法数据不升级为运行结果。


## 2026-10-19 六项修订候选规范

材质token与原确认截图保持原样。本轮只补交互层级和组件状态；新稿须用户评审后再形成新的正式参考。

- Select使用共享自定义触发器与浮层，中性磨砂、同族chevron、当前值及选中勾记；关闭/展开/焦点/禁用/空/加载/失败/长列表均须设计。设置和会话筛选复用，不能让浏览器默认下拉决定外观。参考Apple [Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons)与[Menus](https://developer.apple.com/design/human-interface-guidelines/menus)，继承本项目已确认配色。
- HUD工具栏/手柄为空白拖区，正文和交互控件不作为拖区。菜单点击释放后保留，操作行固定，只有正文内容区滚动；快捷键标记展示实际绑定，未注册/冲突不能伪装有效。
- 半透明底板与文字分别处理，避免降低整个HUD opacity。浏览器只表达同背景设计材质，真正原生背景采样须正式包；减少透明度用实底并保留文字对比。
- 分词边界、注音、词性独立可见；仅注音时不要悄悄开启词性颜色或分词底纹。ruby上方有空间，长文不裁切；词法失败保留原文与可理解状态，不假造读音。
- 会话正文/全部提取/Hook事件的标题和范围清楚；总量与已加载量分开，新内容不抢走正在查看旧内容的滚动位置。完整历史不等于无限DOM列表。
- 运行预览区保留窗口身份、来源/时间与空/停用/旧帧状态。评审工具可切拒绝/退出故障，正式产品不出现评审工具或设计回放控制。
- 按钮普通/悬停/按下/键盘焦点/禁用/选中遵守同一中性层级，线性图标不加突兀彩底；轻返回不变成大块主按钮。组件状态页为评审工具，不作为正式产品导航需求。

### HUD常用操作分组（本轮追加）

浮窗顶部轻工具提供置顶、布局切换、隐藏，保留空白拖动手柄；底栏以固定32pt控制行分组显示分词/注音/词性、原文译文模式、翻译开关、暂停/继续、重译、复制、精读和更多。高频项不再同时放入更多菜单。更多仅设置、关联/解除关联、位置恢复、断开；无当前原句的操作真实禁用，保留title/可访问名称和快捷键说明。560/500及小屏必须操作可达，不靠横向整窗滚动暴露按钮。

## 2026-10-27 已确认：紧凑运行窗口预览

用户已明确采用[紧凑方案](../../../.build/stability-refactor-20261027/compact-preview-design-v1/index.html)，用于完整稿的当前会话与选窗核对面板。两处复用同一组件，沿用本页中性磨砂层次和 `icons.js` 图标族，不增加材质token或另一套强调色。

- 标准主卡外框为282×346；窄侧栏按实际可用宽度布局，260压力条件也应保持按钮和信息入口可达。720及以上宽卡可横向重排，但以组件容器宽度为依据：1600桌面中的262侧栏仍是紧凑卡。
- 主卡分为标题与详情入口、16:9画面、原采集时间与身份摘要/行动建议、固定常用操作。原图采用 `object-fit:contain`，完整显示、不裁剪、不拉伸。主文案保持12/13px，辅助信息11px；不能靠缩字、缩放、裁按钮或整卡滚动适配。
- 主卡始终保留游戏、状态、精确原采集时间、身份核对要点、刷新和暂停/继续。失败时增加对应的单一恢复动作；自动预览不重新增加手动开启开关。旧帧明确标最后画面，失败或刷新同一帧不伪造新时间；身份不符不复用旧对象画面。
- 完整标题/路径、Bottle/EXE、Windows及宿主启动身份、窗口ID、hash、阶段/API/请求/Native状态、原始原因及完整隐私说明均从真正可打开的详情层读取、选择和复制。长标题可在主卡显示两行，但完整名称保留可访问名称并在详情可查。
- 只有详情正文允许滚动，详情标题与复制行固定；主卡与其根视图不整体滚动。Tab/Shift+Tab在弹出层内循环，Escape关闭，焦点回到同对象的触发按钮；详情键盘不触发底层阅读快捷键。
- 覆盖实时、暂停、正在开启、权限缺失、暂不可用、退出、身份异常，以及长游戏名、长错误和日语文本。系统授权/重新选窗等恢复入口在离线稿只演示下一步，不能把点击等同于真实权限、采集或Hook成功。

原批准PNG、旧布局/候选和token指纹保留。新完整稿截图输出至独立 `.build` 运行目录；浏览器设计与正式包的原生材质、权限、身份映射和四游戏回归分别验收。
