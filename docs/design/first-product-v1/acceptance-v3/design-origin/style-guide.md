## 共同的窗口语言

以整个窗体连续的暗蓝灰磨砂底为基础，背景的蓝色、亮部与暗部经过模糊后透入。标题栏、导航和正文属于同一窗体，不切成互不相干的白、青、灰色大块。

表单、输入区、阅读提示和结构卡片使用更厚的中性灰内层表面；文字和图标保持独立清晰。边界以细暗线、局部高光和柔和阴影表达，不增加连续明亮外框或装饰性玻璃按钮。

| 层次 | 共享变量与默认值 | 使用位置 |
| --- | --- | --- |
| 窗体 | `--material-shell-fill`：rgba(35,38,49,.8965)；25px / 105% | 主窗、设置、学习、字幕 |
| 厚内面 | `--material-inset-fill`：rgba(58,58,68,.863)；20px / 90% | 分组表单、输入、原文卡与解释卡 |
| 控件与选择 | 中性灰透明填充、柔和浅灰选择态 | 按钮、分段控件、列表选择 |
| 主要文字 | #e9e9ef | 原文、译文、标题、字段值 |
| 次要文字 | #b0b2c0；辅助 #9495a5 | 来源、说明、状态与元信息 |
| 强调 | 中性浅灰 #c4c5cf | 链接、焦点、结构引用 |
| 外形 | 窗体16px、内面13px、控件7px | 同层级保持一致 |

图标统一由 [icons.js](icons.js) 提供：24×24视框、1.65圆头描边、常规18px视觉尺寸，使用currentColor；设置分类和标题不使用彩色底块，不再混用Unicode图标。主要操作采用深灰底、白字，选择与链接靠中性亮度区分；彩色只用于小面积必要状态，背景和游戏画面保留原色。

准确值与浅色适配集中维护在 [material-tokens.css](material-tokens.css)。浅色是同一套层次的可选适配；默认外观采用已确认的暗色案例。

## 覆盖页面

- 游戏库、当前会话、历史与手动翻译共享同一窗体和内容层。
- 目标程序、检查与选流面板继承窗体材质，状态变化不改变整套色调。
- 设置十类导航、服务连接、模型、用途、测试与参数页使用统一分组表单。
- 字幕、词卡、词典和精读采用相同磨砂层次；保留阅读字号、注音、结构引用和32pt操作行。
- 菜单、确认弹窗、失败与恢复提示统一边界、文字、按钮和状态颜色。
- 截图画廊、旅程和对照页也采用该风格，避免评审入口出现另一套调性。

系统减少透明度时退为同色系实色表面。正文滚动、固定底部操作、200%字号与小屏布局继续有效。

## 验证与边界

Playwright从首次配置、连接与选流开始走完整流程，再采集所有页面；另外直接对照已确认案例与游戏库、设置、字幕、精读截图。检查实际取景、层次和可读性，不能仅凭CSS中有blur参数认定达标。

HTML表现浏览器中的材质视觉。原生材质、窗口行为、游戏与模型功能仍按原开发计划验证；真实游戏画面仍保留此前证据归属，设计用译文与词法数据不升级为运行结果。
