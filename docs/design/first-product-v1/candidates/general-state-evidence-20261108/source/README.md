# 通用设置结构 V3：待评审候选

本稿回应新包通用设置在真实场景中仍显得不协调的反馈。它只存在于独立 `.build` 候选目录，未替换批准源、PRD或客户端实现；前一轮三页局部修复已经安装，不代表本稿已实现或通过验收。

直接打开 `index.html` 对照用户实机与新稿；`settings.html` 是独立的客户端内容画布。均可通过 file:// 打开，不需要开发服务器。默认窗口1000×720；入口可切到760×560、浅色、200%。

| 区域 | 候选组织 | 保留的行为与边界 |
|---|---|---|
| 标题与作用范围 | 同行的“通用”标题和轻作用范围选择 | 全局默认与单游戏字段覆盖分别保存；单游戏轻来源显示当前已保存事实、按需查看覆盖项并恢复继承；草稿未保存时禁止切范围，不改变游戏或Hook |
| 分词与词典 | 页面主体，三行单层标签与说明；词典一行内置状态 | 分词关闭后词性开关禁用，现有偏好保留；注音独立；无需配置或下载基础词典 |
| 阅读记录 | 固定保存状态与“阅读历史”入口 | 不提供关闭保存开关；原文、译文与来源始终保存 |
| 自动输入与翻译 | 轻“当前会话”入口 | 实际暂停、恢复和自动翻译属于当前会话；本页不重复提供一个只在会话存在时可用的开关 |
| 本机偏好 | 登录启动单独一行；异常原因按需展开 | 显示当前系统未找到应用服务、不可启用的事实；不把重装当成已证实解法；重新读取样本仍返回不可用 |
| 保存反馈 | 只反馈阅读偏好的草稿与作用范围 | 本机登录服务状态不与阅读偏好一起伪造保存成功；移除产品范围及实现说明 |

视觉沿用现有 material-tokens.css、icons.js 的中性色和线形图标。常规行仍有14px水平安全边距，未通过缩小字体填入首屏。1000×720下三组完整可见；窄窗和200%使用独立正文滚动，底部保存控件保持可达。

所有交互仅使用网页内存：保存、放弃、全局/游戏范围、禁用词性、鼠标/键盘选择、搜索、详情、历史/会话/其他分类的明确设计回放。不会调用原生服务、HTTP、SQL或当前Luna。对话框均明确说明设计回放，避免把样本导航或不可用服务伪装成实际成功。

`verify.mjs` 使用项目锁定的 Playwright 浏览器，以 file:// 验证8个尺寸/主题/缩放组合，逐个开关实际滚到正文可视区再鼠标点击、保值禁用、真实底部保存及Space键；另验证范围隔离/保存/放弃与导航样本，以及入口的对照、尺寸、主题、缩放、重置和所有SVG。11项通过，V2原稿及其QA保持原字节；V3先前轮次原件保留在 validation-round-*，最终回执和21张PNG在 validation/。

这些只证明候选可读和交互可执行，不构成用户批准、生产组件验证、Native或发布通过。单游戏覆盖只保存主动编辑的字段，其余字段从最新全局已保存偏好实时解析。恢复继承只修改游戏草稿，保存后才清除游戏覆盖；放弃恢复会继续使用原游戏覆盖。候选测试核对恢复前后全局记录不被修改，并通过随后修改全局、再回到游戏范围证实继承不是永久复制。

确认后才更新现行PRD、客户端设计与测试，并用现有C04 Select和M13偏好端口实施；Rust权威与登录服务能力回执保持不变。仍需独立正式组件截图及真实包验收。
