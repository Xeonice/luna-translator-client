## 待确认的具体增量

| 设计状态 | 页面反馈 | 草稿与操作 |
| --- | --- | --- |
| 偏好读取中，已有上次已读值 | 在原标题下显示“正在读取已保存的阅读偏好来源…”；底栏“正在核对阅读偏好” | 旧值保留但暂不可编辑；范围、保存、放弃暂禁用。读取记录、本机偏好不受其控制。 |
| 偏好初次读取，尚无已读值 | 同一个读取中状态的无缓存子态；尚未显示分词开关 | 不把样本默认值当用户已保存偏好。阅读记录、本机偏好仍可用。分词与词典组在已读后出现，不新增空页面。 |
| 来源读取失败 | 标题下显示失败反馈及“重新读取偏好来源”；底栏“阅读偏好来源待确认” | 示例未保存的词性编辑仍为开启；开关与保存暂禁用，允许放弃；重试仍失败也保留草稿。 |
| 保存失败 | 标题下显示“阅读偏好保存失败，请重试。编辑内容已保留。”；底栏仍为未保存 | 词性编辑保留，可继续编辑、放弃或再次保存；设计回放的重试返回失败，不伪造成功。 |

这是三类新增视觉 recipe，其中读取中分别展示有缓存与无缓存两个子态。错误消息是明确的设计样本；生产错误细节仍由真实回执提供。

Normal 和无游戏页面仅是已批准结构与既有语义对照，不要求重新批准已有十一种状态。无游戏时仅有全局范围，仍使用通用页；没有多余的“空游戏库设置”页面。原三组稳态结构、安全边距、700 标题字重、侧栏底部和固定保存栏保持原来源。窄窗和 200% 通过各自内容区滚动访问，不删内容、不缩字、不靠截图裁切隐藏。

## Native 参照外壳：独立待确认

`context=native-proposal` 仅是新参照环境提案：

- HTML 与 body 的**展示底**透明；原 `.window` 仍使用批准的 `--material-shell-fill`。
- 隐藏 HTML 模拟交通灯，保留标题栏尺寸；真正的窗口控件应由 macOS 提供。本网页不模拟这些原生控件。
- 材质 token、fill、alpha、25px blur、105% saturation、边框、布局和字体没有变化。
- Web 模式继续使用 V3 原展示底和模拟窗口钮，不改变原参照上下文。

入口外侧的渐变背景仅说明透明合成关系。`native-context-browser-only-*.png` 是透明网页的浏览器截图，**不是实际 Native 窗口截图**，没有实际 OS 材质、活动窗口或减少透明度验收含义。该上下文需要单独确认，不能由状态增量确认自动批准。
