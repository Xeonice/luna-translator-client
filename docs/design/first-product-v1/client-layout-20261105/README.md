客户端参考生成器应在父源准备完成后、捕获前使用受控容器层，并保存变换前后DOM及源指纹。不能把这项变换伪称坐标归零，也不能从1600px桌面裁切生成客户端图。原稿交互、内容、材质token及零差异阈值不变。

本次确认不提升逐状态PNG、真实React、正式包、Native材质或四游戏结果。实际适配回放仍须重新生成、独立核验和逐态审核。原未通过投影完整保留。
