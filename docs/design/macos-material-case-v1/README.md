## 本案例比较什么

只对照窗口外壳的磨砂半透、背景明暗和蓝色的扩散、内部输入区的材质厚度，以及窗口边框和阴影。参考原样保留；中央窗口裁切只用于相同取景下的比较。

`assets/reference-desktop.png` 是用户提供的原始桌面参考截图。`assets/wallpaper-frame.png` 是独立的干净壁纸帧，供可操作案例用作真实背景；`assets/wallpaper-preview.png` 是其预览。案例窗口没有把参考窗口截图作为背景，也没有将模糊后的整窗截图贴回页面。材质由网页在当前背景上实时应用 `backdrop-filter`，移动窗口时重新采样后方图像。

不能因使用了 `backdrop-filter` 就认定已经达到参考效果。应查看实际截图中的颜色、轮廓、透明层次和边缘，本案例的风格方向现已获用户确认，逐像素差异仍保留说明。叠图和滑动对照是发现差异的工具，没有视觉相似度分数，也没有“完全一致”的通过声明。

## 查看方式

直接双击 `comparison.html` 或 `index.html` 即可从本地打开，不需要 HTTP 服务、网络字体或在线 API。建议使用支持 `backdrop-filter` 的当前 Chrome 或 Safari，在相同浏览器缩放比例下查看。

对照页默认使用窗口裁切并排展示；点击“查看原图”可打开原始尺寸。叠图滑块从仅参考图（0%）过渡到仅案例稿（100%）；滑动揭示的左侧为参考图，右侧为案例稿。分界线可拖动，也可通过键盘操作上方滑块。

截图用于检查同一渲染环境下的实际表现：

| 文件 | 用途 |
| --- | --- |
| `previews/reference-window.png` | 从用户参考截图裁出的中央窗口 |
| `previews/case-window.png` | 同一取景的案例窗口 |
| `previews/blur-off-window.png` | 关闭背景模糊后，观察背景细节是否重新显现 |
| `previews/moved-window.png` | 移动案例窗口后，观察其重新采样后方壁纸 |
| `previews/case-desktop.png` | 案例在整个桌面背景中的比例和材质 |

## 交付边界

这是 HTML/CSS 材质验证稿。网页预览不等同于原生 macOS `NSVisualEffectView` 或系统材质，不证明原生窗口行为、跨平台渲染或性能已经实现。界面文字和图标只服务于材质比较；不调用游戏取文、翻译或模型服务，也不表示这些功能在本案例中可用。

完整首版设计已按用户授权采用此案例的风格。案例确认不等同于整稿布局、原生实现或功能回归通过。
