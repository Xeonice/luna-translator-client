# 历史页：会话筛选与加载较早记录

本稿细化FP-09及MC-20，不改变首版功能集合、存储关系或原始验收编号。[历史页完整设计](../design/first-product-v1/candidates/history-session-paging-20261031/index.html?scenario=history)的R79精确源已纳入[完整设计批准](../development/design-approval-complete-20261031.json)，与原guided57源共同构成当前61源组合；原批准记录、源字节和pending_review捕获标签保留。对应客户端技术合同和CP-11实施计划已同步，客户端按[已确认三页补充](../development/design-approval-layout-refinements-20261107.json)实施；源码、受控组件、独立参照和签名包验收分别留证。

## 页面与范围

历史记录沿用完整主窗、侧栏与暗蓝灰磨砂材质。筛选与正文两栏使用同一`0.86fr / 1.4fr`轨道，每栏内容线内缩16px；右侧会话选择与轻量目录分页位于同一会话轨道，不另开第三列。列表选中背景可延伸至内容线外8px，文字/筛选与详情沿各自16px线对齐。有效内容宽度≤600px时两区顺序呈现，筛选同步单轨，完整内容仍可滚动到达。页头保留“刷新记录”“定位当前句”；游戏和会话使用同一专用Select并明确标签。左侧历史列表、右侧原文/译文/修正详情各自滚动，筛选和加载操作不随整窗滚走；窄窗在同一窗口顺序呈现两区，控件不横向挤出。

游戏选项包含全部游戏与手动输入、手动输入和已入库游戏。会话选项首项为“全部会话”，其余用本地日期时间、游戏/来源和接入状态区分，不能让用户理解内部session ID。一次会话指一次独立接入/阅读范围，不据游戏名把不同读取过程混为一份。切换游戏清除旧会话条件；选择会话后只读该范围。无会话与某会话无正文分别有说明；无会话可切换游戏范围，某会话无正文可返回全部会话。

## 两条独立分页

记录和会话目录各以50条为一批示意，分别保有范围、已加载ID窗口和游标。会话目录的“加载更早会话”是目录旁的轻文字操作，避免与主按钮争夺层级；hover、键盘focus、disabled、loading spinner与失败重试有可辨状态，窄窗和200%下不裁切。该操作不改变记录页；记录的“加载更早记录”只追加当前过滤范围，不回到首页、不重复、不丢选中详情和滚动位置。已到末尾明确显示“已到最早记录/没有更早会话”，不保留会再次触发空请求的假按钮。

首次读取、追加读取、失败重试和结束分别表达。追加失败保留已读列表/选择/原译文，并就近提供重试；切换到新范围失败时，保留可阅读内容必须标明“上一范围的记录”，不能以新筛选标签冒充旧数据。重试保持原请求语义（替换首批或追加下一批）。快速切范围、刷新和取消回放后，旧任务代次失效，不能覆盖新范围或清掉新任务。

## 阅读、修改与定位

历史页浏览范围独立于游戏正在推进的当前句；父窗口刷新或新句到达不清筛选、已加载范围、选中记录、滚动和编辑。记录/会话ID窗口固定后，持续新句不能让offset漂移而重复或漏掉旧页。

编辑译文时禁用范围切换、记录选择、分页、刷新及定位，保留输入/焦点/选择区；保存失败保留草稿，取消编辑直接恢复原译文退出，不增加二次确认。复制、重译和精读均固定当前所选阅读对象。词卡固定点击时的旧词/原句，父游戏推进不偷换学习对象；背景译文迟到只更新对应原记录。

“定位当前句”是明确动作：回到全部游戏/全部会话、固定当前句快照并选中，用户可识别其来源；不能在自然接收新台词时自动执行此动作。

## 状态、批准与验收

候选默认展示正常历史。界面外评审条支持首次加载、记录加载/失败/结束、会话加载/失败/无历史、筛选无正文、长标签与长文；可完成被暂停的设计回放。评审工具不作为正式产品按钮，也不连接真实Hook、数据库或翻译服务。
