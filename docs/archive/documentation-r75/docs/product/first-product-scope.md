## 用户能完成的任务

| 编号 | 首版功能 | 必须可观察的行为 |
|---|---|---|
| FP-01 | 打开与恢复 | 首次启动为空库，提供添加与连接运行游戏入口；恢复才展示已有记录；主窗关闭与退出不同 |
| FP-02 | 游戏入库与执行环境 | 选择/拖入程序，核对环境、Bottle与实际EXE后入库；首版只连接已运行游戏，页头提供统一入口，详情不重复连接或启动；本机封面优先，无图且正式关联有效目标/已授录屏时，仅保存首张有效帧为托管封面；不覆盖已有图；编辑/移出不删除游戏文件，不同容器独立 |
| FP-03 | 目标选择、连接与选流 | 在同一面板选择窗口或进程并核对完整身份，一次确认“关联并接入”即启动Hook；有效目标且已有权限时自动预览，绑定后会话常驻，缺权限给授权与自动恢复；收到候选后显式选择正文；取消不改现有会话；x86/x64自动匹配，不手拼DLL |
| FP-04 | 连续阅读 | 游戏画面上独立半透明HUD，主窗当前正文独立首屏，原文先显示、译文随后；分词与注音在真实文本中可观察，切换即时作用于当前句；长文仅正文区域滚动，标题栏与操作不随整窗滚动 |
| FP-05 | 阅读控制与窗口关联 | 同目标复用、不同目标确认切换；失败可重试；解除关联保留取文；暂停、翻译、隐藏、断开分别操作；HUD有明确拖动区、位置恢复与可配置快捷键，注册失败和冲突可见，有菜单恢复 |
| FP-06 | 翻译与模型 | 真实产品应支持传统/LLM/本机服务；按用途与品牌/明确接口引导，只填当前必要字段；底层连接/模型/用途与草稿/测试/应用/启用保留；精读/查词独立按需展开 |
| FP-07 | 内置查词 | 无网络首启也有真实分词与基础释义；原文与词法span对齐、读音不编造，点词锚定词卡；失败保留可读原文并显示可恢复状态 |
| FP-08 | 按需精读 | 独立学习窗固定原句；未配模型往返不丢对象；用户开始；等待、失败、取消、结构化/文字模式及歧义可辨 |
| FP-09 | 阅读记录 | 按游戏/会话查看原文译文与来源；当前会话另可回看从接入开始的全部提取事件（含选流前与未选流），正文历史、全部提取和Hook诊断在当前阅读后方同页独立且默认折叠，数量/警告/缺口摘要可见，筛选/分页/跟随互不污染；完整分页/搜索/导出不受首屏条数截断；重译、人工修正与固定旧句学习保留 |
| FP-10 | 无游戏使用 | 手动输入日语能进入同一翻译/查词/精读流程，不以Hook就绪为前置 |
| FP-11 | 偏好与资源 | 内置词典版本、分词/注音/POS、字号/明暗/减少透明度、快捷键与全局/游戏配置来源清楚；Select统一使用符合已确认Apple风格的专用组件，包含键盘、焦点、禁用及长文本状态 |
| FP-12 | 诊断与恢复 | 当前会话保留真实有界脱敏Core消息与阶段事实，可查看身份、资源/DLL、引擎、安装地址、错误码与事件顺序；Warning1/2正确分级，默认降噪raw处置且全量可追溯；缺组件、权限、身份变化、无文本、翻译/词法故障及丢失分别表达 |

OCR、语音、Anki/Yomitan、文件批量、对外Web API、原生macOS游戏取字、内嵌回写和后续AI对照/草稿/历史问答继续保留原路线，本高保真稿不将它们伪装成首版已可操作能力。CrossOver设计/验证不替代Windows原机或原生macOS游戏验收。

游戏入库与窗口流程参见[补充PRD](game-library-window-prd.md)。参考原版游戏管理与窗口识别，按用户最新要求将窗口关联确认和Hook接入合并为一次操作；底层仍区分窗口已关联、接入中、已连接与已收到文本。这里的程序多选入库与后续批量翻译文件是不同任务。

六项产品缺口的可验收细节统一见[运行窗口、字幕与会话 PRD](reading-window-session-prd.md)（RW-01～34）。本轮补充的截图仅用于窗口确认与阅读辅助，不识别图片文字、不启动OCR，仅在用户选择有效运行目标时展示并按系统需要申请录屏权限；已有权限即自动预览。持续预览不录制、不连续存帧；用户本轮明确允许的无封面首张有效帧是独立静态资产用途。会话内全量提取与Hook事件是不同数据视图，不将默认诊断日志改成台词全文日志。原有范围编号保持不变；最新设计已评审；须补齐实际实施和逐层发布执行证据后，才能作为下一轮实现依据。

## 高保真交付标准

提供[完整可交互原型](../design/first-product-v1/index.html)，以macOS桌面和独立窗口层级体现真实旅程：游戏、HUD、主窗、设置、精读同时保留各自状态，连接与选流为附属面板，短词卡贴近词语。完整旅程从真实入口点击，不靠切换‘成功’状态补步骤。

窗口“关联并接入”已纳入当前整稿：核对后一次确认启动接入，同目标复用、不同目标确认切换、失败重试与解除关联分别表达。[此前客户端切片验证](../development/desktop-client.md#关联并接入版-013)只作为该交互的既有实机证据，不作为首版完整客户端交付。HTML检查与正式产品回归分别记录。

连接、模型、用途、游戏覆盖、草稿/已应用版本、阅读单元和历史有一致的演示数据关系；切换、复制和应用后显示当前实体的真实内容与影响。测试结果明确绑定所选对象/用途，不一次把全部能力标绿。只有评审工具区可标示设计条件和注入故障，产品界面不塞开发实现说明。

使用Playwright截图与原稿对照，检查浅深色、长文/200%、最小桌面尺寸、窗口组合与关键失败恢复。此验收只确认设计交互与视觉，不能代替真实API、分词器、凭据存储、原生窗口或正式包四游戏回归；原55任务/111用例及22条MC仍维持未执行。后续需据本用户确认范围细化执行映射与发布门禁，不能把文档更新当成任务已完成。

既有57项交互与44组浏览器内容对照通过，只证明所选受控状态的实际结果；不能外推为本轮34项新增验收已执行，或原生窗口材质、拖动、全局快捷键、实时窗口帧及真实词法资源已通过。组件与按钮还须按原已确认材质、图标、尺寸、间距和状态逐项审阅，不能用简化后的补充参考替代未覆盖的原要求。
